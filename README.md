# Task-Tracker-App
Basically, the app will contain the pending and completed task and the task will be showed based on the priority or importance of that task 
## Front -End plan
So in the front-end we will make a attractive UI showing users their tasks that they need to completed and all the tasks will be first labeled as not started in red and the task will be shown in a line according to the importance that a user has selected
once a task is started but if user doesnot complete it than that task will shown as pending in yellow color
and the task that are completed will be shown as completed in green and also the time taken by the user to complete that task
## Back-End plan
so in backend we put a notification system where the user gets notification to complete ot start the task
also we will need to put the logic behind the task that shows pending or completed
we will also need to put database integration where the task of specific users are saved so that the user doesnot need to reenter task daily
aslo the singup and login logic and api
